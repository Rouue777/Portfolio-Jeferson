# Portfolio

## Objetivo
Landing page pessoal para apresentar meu perfil profissional,
projetos, tecnologias, experiência e formação.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Lucide React

## Arquitetura
Componentes devem ficar em /components.

Dados estáticos devem ficar em /data.

## Regras
- Não criar backend.
- Não adicionar banco de dados.
- Não instalar dependências sem necessidade.
- Priorizar componentes reutilizáveis.
- Manter TypeScript strict.
- Interface responsiva.
- Não colocar todo o código em page.tsx.

## Design
Estilo:
- dark
- moderno
- tecnológico
- profissional
- minimalista

Cor de destaque:
- roxo/azul

Referência visual:
portfolio moderno de desenvolvedor.
